완료보고서 "AI를 통해 구현한 부분과 본인이 수행한 내용" 항목의 원본이다. 근거는 AI 입력 기록
(`docs/ai-prompts.md`)과 커밋 기록이다. **`[확인 필요]` 표시는 기록만으로 알 수 없어 본인이 직접 채우거나 고쳐야 하는 부분이다.**

## 2. 작업 방식

1. 본인이 방향·범위·우선순위를 정하면 Claude Code가 `PLAN.md`(단일 기준 문서)에 정리한다.
2. 구현은 PLAN.md의 순서대로 한 기능씩 진행한다. "계속", "해줘" 입력은 PLAN.md의 다음 작업을 진행하라는 뜻이다.
3. 규칙은 `CLAUDE.md`로 고정했다: 프레임워크·CSS/차트 라이브러리 금지, 의존성 추가 시 사전 승인, 외부 API 응답은
   실제 호출로 확인(추측 금지), 기능마다 실행해서 동작 확인, 기능 단위 커밋, 비밀 값은 `.env`에만.
4. 기능이 바뀌면 같은 작업 안에서 PLAN.md를 고친다 → PLAN.md의 체크리스트가 곧 구현 기록이다.

## 5. 사이트 안의 AI 기능(Gemini)은 어떻게 쓰는가

- 사이트의 AI는 **숫자를 만들지 않는다.** 숫자는 서버가 DB에서 SQL로 조회·계산하고, AI는 문장만 만든다.
- 어시스턴트: Gemini가 조회 함수(Function Calling)를 고르면 서버가 SQL을 실행해 결과를 돌려주고, 답변과 함께
  "근거 데이터"(호출한 함수·인자·결과 표)를 화면에 보여 준다.
- 리포트·하이라이트: 서버가 만든 근거에 없는 숫자가 답에 나오면 **서버가 자동으로 거부**한다(숫자 검증).
- 모든 AI 결과에 "AI 생성 내용" 표시, 하루 호출 한도, 질문 길이 제한. 사용자 게시글은 AI에 보내지 않는다.
- 자세한 규칙: PLAN.md §8·§8-1
