# F1 PITWALL – 페이지 목록 (Figma 프레임 기준)

프레임: 데스크톱 1440×1024 (한 화면형은 1440×900), 모바일 390×844. 프레임 이름은 `페이지명 / Desktop`, `페이지명 / Mobile` 형식으로 맞춘다.
(신규)는 참고 사이트 반영 항목. 한 화면형 = 스크롤 없이 쓰는 화면(900).

## 공통 요소 (컴포넌트로 먼저 제작)

- 사이드바 / 상단 내비게이션(모바일은 하단 탭 또는 햄버거), 시즌 선택기(신규), 테마 토글(라이트/다크)(신규), 통합 검색 입력
- 순위표 행(팀 컬러 띠 + 순위 + 이름 + 값 + 변동), 카드, 탭, 필터 칩, 모달, 차트 카드, 로딩 스켈레톤, 오류 화면, 알림 토스트
- 상태 색: 최고 랩=보라, 개선=초록, 경고=노랑, 손해=빨강

## 설계 순서 (권장)

1. 공통 컴포넌트와 디자인 토큰
2. 통합 대시보드, 순위, 라이브 타이밍 (핵심 3화면)
3. 결과, 드라이버·팀·서킷, 전략 분석
4. 리플레이, AI 어시스턴트
5. 나머지 페이지

## 참고

- 참고 사이트(app.formula1dashboard.com)는 기능 구성만 참고하고, 디자인은 PITWALL 자체 디자인으로 만든다.
