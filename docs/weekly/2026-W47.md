## 문제와 해결
- 한글 경로가 `URL.pathname`에서 `%인코딩`되어 캐시 폴더가 엉뚱한 곳에 생김 → `fileURLToPath`로 수정.
- DB가 시드니 리전이라 행 단위 INSERT가 13분 → `unnest` 일괄 삽입으로 74초.
- 5432(Session pooler) 접속이 학교·집 네트워크에서 막힘 → 6543(Transaction pooler) 사용.
- Express 5는 `/:kind(a|b)` 경로 문법 미지원 → 라우트 분리.
- 시즌 중 이적 드라이버가 목록에 중복 → 최근 소속 팀 1건만 표시.
- Jolpica 429(호출 한도) → 재시도 backoff, 페이지별 캐시로 중단 후 이어받기.
- 계획서는 Spring이었으나 수업 내용(JavaScript)에 맞춰 **전부 JS로 통일** — 완료보고서에 변경 이유 명시.

### 문제와 해결
- 일괄 수집 스크립트가 호출 한도(429)로 실패했는데 종료 코드 0이라 성공처럼 보임 → 한도는 종료 코드 75로 구분해 기록하고 멈춤.
- 랩 수집이 `lap`·`pit_stop`을 지우고 다시 넣어 OpenF1 값(섹터·스피드트랩·정지 시간)이 사라질 위험 → 일괄 수집에서 2026 랩 제외.
- 라이브 배속을 바꾸면 처음부터 다시 재생 → `start` 파라미터로 현재 시각부터 재연결.
- 헤더 고정 높이(72px) 때문에 좁은 화면에서 검색창이 잘림 → `min-height`로 변경.
- 새 즐겨찾기가 옛 레이스 알림을 쏟아낼 위험 → 최근 14일 결과만 알림 대상.
- 게시판 메뉴를 추가하자 로그인 상태 헤더에서 내비가 잘림 → 1600px 이하에서 내비를 한 줄 아래로. 알림 배지가 0일 때도 보이던 문제(`hidden`이 CSS `display`에 덮임) 수정.
